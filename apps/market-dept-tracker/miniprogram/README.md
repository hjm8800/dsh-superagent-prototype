# 市场部工作台 · 微信小程序

电脑端和手机端都能用。同事进入一次自己的链接，之后打开小程序就看到自己的任务清单。

## 它能做什么

- **我的任务**：只显示自己的任务（上级下达的和每周／每月固定任务），可以直接改状态、写说明。
- **部门总览**（仅领导）：各岗位已交成果数、完成度、任务完成情况、认不出的文件数。
- 登录用部门发的专属链接，不用账号密码；电脑上的微信打开小程序也能用同一个链接。

它和网页版读同一份数据，一边改了另一边立刻能看到。

## 目录

```
miniprogram/
  app.js              启动、记住链接、发请求
  app.json            页面与底部标签
  app.wxss            样式
  project.config.json 开发者工具的项目配置
  pages/
    login/            粘贴链接进入
    tasks/            我的任务（默认页）
    overview/         部门总览（仅领导）
  sitemap.json
```

## 怎么发起来

小程序不是把代码放上去就能用的，它要挂在微信的账号下面。三件事：

### 1. 注册小程序，拿到 AppID

到 <https://mp.weixin.qq.com> 注册一个「小程序」账号，在「开发 → 开发管理 → 开发设置」里能看到 AppID。
把 `project.config.json` 里的 `"appid"` 从 `touristappid` 改成这个 AppID。

### 2. 把平台放到有域名的服务器上

小程序只能请求 **HTTPS** 的地址，而且域名要在微信后台白名单里，所以平台不能只跑在某个人的电脑上。

- 找一台常开的机器（公司服务器或云主机），把平台跑起来：
  ```bash
  node lib/src/cli.js --port 3000 --host 0.0.0.0 --base https://mkt.example.com
  ```
- 前面挂一层 HTTPS（Nginx + 证书，或用云厂商的负载均衡），让它对外的地址是 `https://你的域名`。
- 到微信后台「开发 → 开发管理 → 服务器域名 → request 合法域名」把这个域名加进去。

然后把 `miniprogram/app.js` 第一行的地址改掉：

```js
const BASE_URL = 'https://mkt.example.com'
```

### 3. 用微信开发者工具上传

1. 装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 「导入项目」，目录选本文件夹里的 `miniprogram/`，填上你的 AppID。
3. 本地能预览后，点「上传」，填版本号和备注。
4. 到微信后台「管理 → 版本管理」把刚上传的版本提交审核，审核通过后发布。

审核时说明这是个内部使用的部门工作台即可；个人主体也能注册和发布。

## 用法

1. 部门负责人把每个人的专属链接发下去（网页版「填报链接」页可以一键复制）。
2. 同事在微信里打开小程序，把链接粘贴进去，点「进入」。
3. 之后打开小程序就直接是自己的任务清单；换人时点「换个链接」。

## 和网页版的关系

两个前端，一个后端：

```
             ┌── 网页（浏览器）  /  /tasks  /ledger ...
数据库 ── 服务 ┤
             └── 小程序        /api/me  /api/my-tasks  /api/overview
```

小程序用的是 `/api/…` 这组接口，和网页走的是同一份数据和同一套权限规则。

## 接口

| 方法 | 地址 | 说明 |
| --- | --- | --- |
| GET | `/api/me?token=` | 这个链接是谁、哪个岗位、能不能看全部门 |
| GET | `/api/periods?type=week` | 可选的周／月 |
| GET | `/api/my-tasks?token=&type=&period=` | 自己的任务清单 |
| POST | `/api/my-tasks/status` | 改任务状态，表单字段 `token`、`id`、`status`、`note` |
| GET | `/api/overview?token=&type=&period=` | 部门总览（仅领导） |

## 还没到位的

- AppID、HTTPS 域名、审核发布这三步只能由管理员来做，代码里已经留好位置。
- 小程序目前不包含：下达任务（只在网页版）、成果采集（网页版和命令行）、填报周报（网页版）。如果这些也要在小程序里，可以再加页面。
