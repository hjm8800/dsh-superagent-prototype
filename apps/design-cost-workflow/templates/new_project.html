创建后会发生什么

  1. 自动编号：生成 PRJ-YYYYMMDD-NN 项目编码，工程类型 / 地点 / 备注按填写内容保存。
  2. 自动初始化四阶段：“图纸解析”为进行中，建模 / 算量 / 计价为未开始，并按阶段门禁推进。
  3. 跳转到图纸解析页：可直接上传施工图、设计说明书或材料清册，识别后提交复核。
  4. 可见性：演示环境下所有账号（管理员 / 造价员 / 复核员）均可查看该项目。
  5. 审计留痕：创建动作写入审计日志，可在项目页“审计动态”查看。
