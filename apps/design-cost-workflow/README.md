# 设计图纸 → 建模 → 算量 → 计价 工作流原型（MVP）

配电网工程（10kV 及以下）从设计图纸到施工图预算的可运行原型：把图纸解析、建模、算量、计价四个阶段串成一条链路，带阶段门禁、角色权限、复核留痕、设计预算对比、（v2）南网 V3.1 典型设计（典设）模块匹配，以及（v3）“开始工作流”入口与简单项目建档。演示数据已匿名化为项目 A/B/C。

> **说明**：应用内的定额子目与主材单价为**示例数据（演示用）**，不是官方定额或企业正式价格；费用构成、取费基数与费率按 2022 版《20kV 及以下配电网工程建设预算编制与计算规定》编制（演示取江西 Ⅰ 类地区、县城或镇参数）。正式项目请替换为正式定额库并人工复核。

## 功能

- **开始工作流（v3）**：工作台顶部“开始工作流（三步走）”引导区——新建项目 / 图纸解析→建模→算量→计价逐阶段提交复核 / 对比与导出，主按钮“＋ 新建项目，从图纸解析开始”，次按钮“5 分钟演示路线”；登录页与演示路线页也有开始提示。
- **新建项目（v3，`/project/new`）**：造价员/管理员填写项目名称（必填，≤60 字）、类型（台区改造/业扩配套/技改修理/其他）、地点、备注，系统自动生成项目编码 `PRJ-YYYYMMDD-NN`、初始化四阶段（图纸解析=进行中）、把演示账号加入成员，创建后跳转图纸解析页可直接上传图纸；复核员只读。
- **工作台（`/`）**：开始工作流引导区、项目卡片（当前阶段、进度条、设计预算、模型预算）、统计卡、待办与风险提醒。
- **项目工作流（`/project/{id}`）**：四阶段 stepper（状态、负责人、时间、版本）、“下一步”引导条（按当前阶段提示动作与跳转按钮）、阶段操作按钮、预算对比卡、审计动态。
- **图纸解析**：图纸目录（状态：待识别/已识别/需插件/解析失败）、多文件上传后自动解析并生成识别摘要、数据线索；支持由已识别图纸生成建模初稿。
- **典型设计匹配（v2，`/project/{id}/typdesign`）**：导入南网 V3.1 典设模块目录（XLSX/CSV，兼容附件6-1“V3.1 模块汇总表（参考）”双表结构）；一键匹配图纸摘要/说明书/模型/算量数据中的典设模块编号（编号精确/图号序列/编号变体/名称推断，带置信度与证据来源）；逐项“确认应用/忽略”（可填应用数量、备注）；导出《典型设计匹配清单》（可作为附件6-1 图纸依据底稿）；匹配状态同步展示在图纸解析页、项目工作流页、建模页与对比页送审条件。
- **建模**：线路/设备/主材/土建/拆除五类表格的新增、修改、删除；模型校验（高/中/低三级问题）；服务端生成 SVG 平面示意图；由图纸生成模型初稿。
- **算量**：按固定规则重算工程量（含计算式与依据），生成工程量清单；与设计材料清册自动比对（设计量/模型量/差异率/正常·关注·异常归因）；导出工程量清单 Excel。
- **计价**：套用示例定额库（可人工更换定额子目）、按 2022 版费用构成与费率取费、费用汇总、与设计预算（附件 5）对比、导出预算书 Excel；页面提供计价差异说明。
- **对比页**：材料量对比 + 预算对比 + 差异说明 + 风险清单 + 送审条件。
- **复核与审计**：提交复核、复核通过/退回、版本号、复核记录与审计日志；复核人不能同时是提交人（管理员除外）。
- **角色权限**：造价员/复核员/管理员三种登录角色；编辑、提交、复核按钮按角色与阶段状态显示，越权操作被拒绝。
- **演示路线页（`/demo`）**：项目 C 的 5 分钟演示路线，逐步链接到各阶段。

## 运行

要求 Python 3.10+（本机已验证 3.14），依赖见 `requirements.txt`。

### Windows 一键启动

```powershell
cd apps/design-cost-workflow
.\start.ps1
```

打开 <http://127.0.0.1:8091> 。脚本按 `PYTHON` 环境变量 → `py` 启动器 → `python` 的顺序查找解释器（可用 `$env:PYTHON = "C:\path\to\python.exe"` 指定）；如系统 PowerShell 执行策略禁止运行未签名脚本，可改用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
# 或直接启动：
python -m uvicorn app:app --host 127.0.0.1 --port 8091
```

首次启动会自动建库并写入演示数据（`data/workflow.db`）。

### Linux / macOS

```bash
cd apps/design-cost-workflow
bash start.sh
```

### 直接启动（开发用）

```bash
cd apps/design-cost-workflow
python -m pip install -r requirements.txt
```

## 快速开始（从零新建项目）

1. **登录**：如 `zaojia/123456`（造价员）登录；复核员只能查看、不能新建项目。
2. **进入新建项目**：工作台顶部“开始工作流（三步走）”引导区 → 点击“＋ 新建项目，从图纸解析开始”（或直接访问 `/project/new`）。
3. **填写项目**：项目名称（必填，≤60 字）、类型（台区改造/业扩配套/技改修理/其他）、地点（选填，默认“某供电所”）、备注（选填）；保存后自动生成项目编码 `PRJ-YYYYMMDD-NN` 并初始化四阶段（图纸解析=进行中）。
4. **从图纸解析开始**：创建成功即跳转到该项目的图纸解析页，上传施工图/说明书 → 识别 → 提交复核；之后按 建模 → 算量 → 计价 → 对比 逐阶段推进，项目页“下一步”引导条会提示当前应做什么。
5. **不想从零开始**：可回到工作台选择演示项目 A/B/C（四阶段完成态 / 算量待复核 / 图纸解析进行中），或点“5 分钟演示路线”。

## 5 分钟演示路线（项目 C）

项目 C 初始处于“图纸解析·进行中”，适合完整演示四阶段（若要从零体验建档，见上节“快速开始”）：

1. **登录**：用 `zaojia/123456`（造价员）登录，进入工作台，查看三个项目的阶段与金额；打开“项目C·某业扩配套工程”。
2. **图纸解析**：查看图纸目录（说明书、10kV/0.4kV 平面图、台架变安装图、杆塔明细表、材料清册、施工图预算等）与识别摘要；可上传示例 PDF/XLSX/DWG 体验解析（DWG 未装 ODA 插件时显示“需插件”）。项目C 已内置 40 条演示典设目录，可先做典型设计匹配（下一步），再“由已识别图纸生成模型初稿”并提交复核。
3. **典型设计匹配**：打开项目内导航“典型设计”页（项目C 仅导入目录、未执行匹配）→ 点击“执行匹配”，查看匹配明细、匹配方式（编号精确/图号序列/编号变体/名称推断）、置信度与证据来源 → 对 1–2 项点击“确认应用”（可填应用数量、备注）→ 导出《典型设计匹配清单》Excel。也可打开项目A 看已确认完成态、项目B 看待确认状态。
4. **复核**：用 `fuhe/123456`（复核员）登录，在项目工作流页“复核通过”，图纸阶段变为“已完成”，建模阶段自动进入“进行中”。
5. **建模**：回到造价员身份，在建模页校正线路/设备/主材/土建/拆除数据，查看“典设匹配参考”面板（已确认模块，只读），执行“模型校验”（无高级问题后提交），提交并复核通过。
6. **算量**：点击“重新计算工程量”，查看每条清单的计算式与依据、材料量对比（如低压导线设计 0.060km → 模型 0.0618km，+3% 预留为正常），提交并复核通过。
7. **计价**：点击“重新计价”，查看费用汇总（安装/建筑/拆除/设备购置费/其他费用/基本预备费/静态投资）、更换定额子目、查看与设计预算的差异说明（“AI 差异说明”栏为规则生成）；导出“施工图预算”Excel，提交并复核通过。
8. **对比**：打开对比页查看材料量与预算差异清单、送审条件（含“典型设计应用匹配已完成”检查项）；也可在工作台打开项目 A（四阶段完成态）查看已定稿项目，或项目 B（算量待复核）查看复核门禁与“拉线 +6 条”异常差异。

演示入口 `/demo` 提供四阶段路线的说明与快捷链接；典型设计匹配页可从项目内导航“典型设计”进入（或从图纸解析页/项目工作流页的典设卡片进入）。

## 解析插件说明

上传文件保存在 `WORKFLOW_DATA_DIR/uploads/{project_id}/`，单个文件解析失败不影响其他文件；“需插件/解析失败”的图纸会登记在目录中，可人工编目后继续流程。

| 格式 | 解析方式 | 说明 |
| --- | --- | --- |
| PDF | 内置 PyMuPDF | 抽取文本，正则识别路径长度、杆塔数量、配变容量、导线型号等，生成识别摘要 |
| XLSX / XLSM / XLS | 内置 openpyxl / xlrd | 读取工作表名、表头与有效行数，辅助识别材料清册、杆塔明细表和预算 |
| DWG / DXF | ODA File Converter + ezdxf | 检测本机 ODA File Converter（常见路径 `C:\Program Files\ODA\...`），转 DXF 后读取图面文字；未安装时标记“需插件” |
| DOCX / DOC | 内置 python-docx | 读取说明书段落与表格文本（老版 `.doc` 建议另存为 `.docx` 或 PDF） |
| JPG / PNG / BMP / GIF / WEBP | 内置 Pillow | 读取图片尺寸并按“现场照片/图纸图片”编目 |
| BDY3 | 需预算软件厂商插件（二期） | 原型不解析 BDY3 原生格式；设计预算请使用博微导出的 XLSX 作为对比基准 |

上传限制：单文件不超过 50MB；支持 `.pdf .dwg .dxf .xlsx .xlsm .xls .docx .doc .jpg .jpeg .png .bmp .gif .webp`。

**典型设计目录导入：** `/project/{id}/typdesign` 支持上传典设目录 `.xlsx/.xlsm`（兼容附件6-1 双表结构，优先“V3.1 模块汇总表（参考）”）或 `.csv`（UTF-8/GBK），字段为序号、卷册、类别、模块编号、模块名称、模块单位（单文件不超过 20MB）；导入后即可执行匹配。

## 数据与目录

- 数据库：`data/workflow.db`（首次启动自动创建并写入演示数据，含项目 A/B/C 的 40 条演示典设目录与匹配状态）。

## 技术栈

FastAPI + SQLite + Jinja2 服务端渲染；openpyxl 导出 Excel；itsdangerous 签名会话；解析使用 PyMuPDF、xlrd、ezdxf、Pillow、python-docx；模型平面示意图为服务端拼接 SVG。

代码结构：`app.py`（路由/页面/权限/导出）、`parsers.py`（图纸解析）、`typdesign.py`（典设目录解析/匹配/确认/导出）、`seed.py`（建库与演示数据）、`rates.py`（费率/示例定额库/主材价）、`engine.py`（建模/校验/算量/阶段状态机）、`pricing.py`（计价/预算对比）、`templates/`、`static/`、`tests/`。

## MVP 边界

- 演示数据为匿名项目 A/B/C，账号为内置演示账号；**已支持简单项目建档**（名称/类型/地点/备注，自动编码与四阶段初始化，所有演示账号可见），尚未实现用户管理与项目删除，统一身份（SSO）二期接入。
- 示例定额库与主材价为**演示数据**，非正式定额与市场价；未接正式 2022 版定额库、企业价格库，二期替换。
- 未接博微软件与 BDY3 原生格式：设计预算以博微导出的 XLSX 作为对比基准，预算书以 Excel 导出（二期评估格式对接/直连）。
- 典型设计匹配使用内置演示典设目录（40 条节选，**非完整南网 V3.1 库**），匹配为规则推断、必须人工确认；未接入完整典设库/目录版本管理/图纸图像识别（OCR、图框级），正式使用需导入真实目录并人工复核。
- DWG 解析依赖 ODA File Converter；BDY3 需厂商插件；未安装插件时降级为“需插件”并人工编目，不阻断流程。
- AI 能力为规则引擎模拟（识别摘要、模型初稿、校验提示、差异归因），**未接入大模型**；AI 不签章、不直接定价、金额人工复核。
- 单机 SQLite 单进程运行，适合本地/内网演示与试点验证；非生产部署形态（无高并发、备份与审计归档策略），上线需内网服务器、账号体系与备份方案。
- 未做飞书待办推送、审批流与结算定案对接，二期/三期规划见 `docs/design-cost/workflow-design.md`。
