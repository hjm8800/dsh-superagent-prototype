# 竣工资料与结算逐项对比工作流（MVP）

对一个项目的**原版资料**与**新版资料**做逐项对比，自动输出《数据对比表》和《文字分析报告》。适用于配网大修/检修类项目：

- **竣工资料工程量描述**：竣工报告工作簿中的“主要工程量”文字描述、隐蔽接地记录、安健环工程量见证表、清理旧线路设施登记表、拉盘/底盘记录、工程量签证表；
- **材料清册**：甲供/乙供未计价材料汇总表、配件汇总表；
- **审核结算**：检修工程总表（表一）、设备检修专业汇总表（表二甲）、设备检修单位工程表（表三甲）。

## 功能

- **自动识别**：扫描老/新资料目录，按工作表特征自动识别“结算书”与“竣工报告”两类工作簿（支持 `.xlsx/.xlsm/.xls`）。
- **逐项对比**：定额、主材、配件、材料按“编号/名称+规格+单位”匹配，输出 新增/删除/数量增加/减少/单价变化/金额变化/规格变化/单位变化/无变化 九类状态，并计算差异金额与变化率。
- **风险分级**：按金额差与变化率自动标注 高/中/低 风险；新增/删除/规格/单位变化至少中风险。
- **多口径结算对比**：表一口径（设备检修费）、下浮后送审口径、含配件完整口径三种口径同时给出，避免“降/平”结论被口径误导。
- **材料分口径**：乙供未计价材料逐项对比；甲供、配件单独作为补充口径（原版缺清单时明确标注、不误报为新增）。
- **竣工工程量**：文字描述按“同位置+相似度”配对（无变化/修改/新增/删除），接地工程量按材料汇总对比；原资料缺项自动形成“资料完整性”发现。
- **输出物**：
  - `*-数据对比表.xlsx`：总览、审核结算汇总/逐项/新增删除、材料清册（乙供/甲供/配件/主材口径）、竣工工程量（接地/安健环拆旧/文字描述/全文）、风险与建议、说明，共 15+ 个工作表；
  - `*-对比分析报告.md` / `.docx`：中文文字分析报告（结论、依据、风险、建议）；
  - `*-summary.json`：机读汇总，便于后续接入其它系统或 agent。

## 快速开始

要求 Python 3.10+（本机验证 3.14），依赖见 `requirements.txt`。

```powershell
cd apps/settlement-diff-workflow
python -m pip install -r requirements.txt

# 1) 用匿名演示资料跑完整流程（生成 examples/demo 与 demo-output）
python cli.py demo

# 2) 对真实项目资料跑对比（只读取输入目录，不修改原始资料）
python cli.py analyze `
  --old "D:\资料\项目X\2025年资料" `
  --new "D:\资料\项目X\2026年资料" `
  --project "项目X·某10kV线路大修" `
  --out "D:\资料\项目X\对比结果"
```

输出目录会生成：`<项目名>-数据对比表.xlsx`、`<项目名>-对比分析报告.md`、`<项目名>-对比分析报告.docx`、`<项目名>-summary.json`。

其它命令：

```powershell
python cli.py make-demo --out examples/demo   # 重新生成匿名演示资料
python -m pytest -q                            # 运行测试
```

## 输入资料要求

老/新版各放在一个目录里，工作簿按内容自动识别，不依赖文件名：

| 类别 | 工作簿 | 关键工作表 |
| --- | --- | --- |
| 审核结算 | 检修结算书 `.xlsx` | `检修工程总表(表一)`、`设备检修专业汇总表(表二甲)`（可缺）、`设备检修单位工程表(表三甲)` |
| 材料清册 | 检修结算书 | `甲供未计价材料汇总表`、`乙供未计价材料汇总表`、`甲供配件汇总表`、`配件汇总表`（缺表容错） |
| 竣工资料工程量 | 竣工报告 `.XLS/.xlsx` | `竣工报告`（长文本）、`隐蔽-接地汇总*`、`安健环工程量见证表`、`清理旧线路设施工程量登记表`、`隐蔽-拉盘/底盘`、`工程量签证表` |

- 表三甲按真实版式解析：多行表头（第 3–5 行）、`类型`列区分 `项目划分/定额/主材/配件/取费表/小计`；不要求工作簿与模板完全一致，但差异过大时会进入 warnings 并跳过无法识别的行。
- 材料/工程量的名称、规格写法跨年份可能不同（如“混凝土杆 普通混凝土电杆 Φ190*15” vs “预应力混凝土电杆 Φ190×15M”），工作流会做规范化与相似匹配，并在结果中标注“名称相似/疑似改名”，最终需人工确认。
- 原版资料缺表、空记录、口径不一致会作为“资料完整性/口径发现”写入报告，不会伪造数据。

## 对比与风险规则

- **匹配**：定额按“定额编号+单位”；材料按“名称+规格+单位”；同名多行先聚合；再按“名称+单位”（规格变化）、“名称相似（≥82%）”、“疑似改名（≥70%）”逐级匹配，剩余为新增/删除。
- **状态优先级**：数量变化 > 规格变化 > 单位变化 > 单价变化 > 金额变化 > 无变化；单位不同但同量纲时先换算再比。
- **风险**：
  - 高：金额差 ≥ 5000 元，或（变化率 ≥10% 且金额差 ≥500 元）；
  - 中：金额差 ≥1000 元，或（变化率 ≥3% 且金额差 ≥100 元）；
  - 低：其它变化；新增/删除/规格/单位变化至少中风险（金额差 ≥5000 元记高）。
- **结算口径**：原版取表一“设备检修费/施工费”；新版优先取“下浮后送审金额”，无则取设备检修费；报告同时给出三种口径（表一/下浮后/含配件完整）。

## 演示数据

`examples/demo/原版` 与 `examples/demo/新版` 是匿名化演示资料（项目 A，全部名称、金额均为虚构），由 `diffworkflow/demo_data.py` 可重复生成，用于快速体验与回归测试：

- 原版：结算书（表一/表二甲/表三甲/乙供材料）+ 竣工报告（2 段文字、空接地记录）；
- 新版：送审结算书（表一含下浮、表三甲、甲供/乙供/配件、施工费明细）+ 竣工报告（4 段文字、接地 7 个地点、安健环 10 条、拆旧 16 条、拉盘/底盘）。

**真实项目资料与对比结果不要提交到本仓库**；本仓库只提交工具、匿名演示数据与测试。

## 目录结构

```
diffworkflow/
  readers/settlement.py   # 检修结算书 → items/totals/categories/materials
  readers/report.py       # 竣工报告 → texts/tables/items
  normalize.py            # 文本/单位/数字规范化与换算
  matching.py             # 逐项匹配（含聚合/相似/改名）
  diff.py                 # 差异状态、风险、汇总、文本块对比
  build.py                # 扫描目录→识别→组装→分析结论
  export_excel.py         # 数据对比表 Excel
  export_report.py        # 文字分析报告 Markdown/docx
  demo_data.py            # 匿名演示资料生成
cli.py                    # analyze / demo / make-demo
tests/                    # 单元 + 集成测试
```

## MVP 边界

- 只覆盖上述两类来源工作簿的工作表结构；其它格式（PDF/DOCX/博微 BDY3 等）需新增 reader。
- 解析按表头和行内“类型”识别，个别表若版式差异较大会跳过并提示；正式使用前需人工抽查核对。
- 未包含登录/权限/审批流/多人协作；判断与结论为规则生成，供复核底稿使用，不代替人工签认。
- 演示与真实数据处理均在本地，不上传任何外部服务。
